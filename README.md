#  Foodpanda Sales & Customer Analytics Dashboard

A comprehensive end-to-end data analytics and business intelligence project built using **Power BI**, designed to analyze Foodpanda's restaurant transaction performance, customer behavior, delivery metrics, and regional revenue trends.

---

##  Project Overview
This project simulates real-world food delivery analytics to uncover key business insights. It helps stakeholders evaluate restaurant popularity, track order statuses (Completed, Cancelled, Delayed), monitor customer loyalty, and identify top-performing food categories across different cities.

##  Tech Stack & Tools Used
* **Data Modeling & Transformation:** Power Query, DAX (Data Analysis Expressions)
* **Visualization:** Power BI (16:9 Custom Canvas Design)
* **Design Theme:** Custom Foodpanda-inspired Pink/White UI/UX Branding
* **Version Control:** Git & GitHub

---

##  Key Dashboard Features & Metrics
1. **Dynamic Category & Item Slicing:** Interactive item selectors (Burgers, Pizzas, Pasta, Fries, Sandwich) that dynamically update all metrics on the canvas.
2. **Advanced Star Rating System:** Implemented a dynamic Unicode-based star rating measure using DAX (`ROUND`, `REPT`) that adapts based on live data values.
3. **Order Lifecycle Analytics:** Tracks completed, cancelled, and delayed orders with visual status indicators.
4. **Geospatial Revenue Mapping:** Interactive map visual mapping out city-wise revenue distribution (Karachi, Lahore, Islamabad, Multan, etc.).
5. **Customer Segmentation & Loyalty:** Analyzes user age groups (Teenagers, Seniors, etc.) alongside revenue growth trends over months and quarters.
